## Texto para la publicación

Instagram y una página web no cumplen la misma función.

Instagram ayuda a que nuevas personas descubran tu negocio. Una página web les permite entender qué ofrecés, encontrar información importante y comunicarse con vos sin depender de una publicación reciente.

No se trata de elegir uno u otro: se trata de que cada canal haga bien su trabajo.

En Briva diseñamos páginas web claras, profesionales y adaptadas a celulares para pequeños negocios.
