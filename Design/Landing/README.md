# Landing Page v1

## Fecha

02/08/2026

## Objetivo

Crear la primera identidad visual de Briva.

## Decisiones

- Estilo minimalista.
- Inspiración: Stripe, Linear y Apple.
- Un solo CTA principal.
- Sin testimonios.
- Notebook + celular mostrando la misma web.
- El foco es vender presencia digital, no páginas web.

## Qué nos gustó

- Hero.
- Colores.
- Espacios.
- Jerarquía visual.
