# Registro de decisiones de UX

Documentamos decisiones de experiencia de usuario cuando afectan cómo una persona entiende o utiliza el producto.

Cada documento debe explicar:

- el problema observado;
- las alternativas consideradas;
- la decisión tomada;
- por qué se tomó;
- cómo se valida;
- qué ticket la implementó.

Esto evita discutir la misma decisión repetidamente y permite entender por qué la interfaz terminó de cierta manera.
