# BRI-005 — Asociar reservas de clases con socios

- Estado: Listo
- Prioridad: P1
- Versión: V1
- Módulo: Clases
- Tipo: Función

## Problema

Actualmente se puede aumentar el número de reservas de una clase, pero no queda registrado qué socio ocupa el cupo. Esto impide cancelar una reserva, comprobar duplicados y conocer las próximas clases de cada persona.

## Resultado esperado

Recepción selecciona una clase y un socio. La reserva queda asociada a ambos y aparece dentro de la ficha del socio.

## Criterios de aceptación

- [ ] La reserva identifica al socio y la clase.
- [ ] No permite reservar dos veces la misma clase para el mismo socio.
- [ ] No permite superar el cupo.
- [ ] No permite reservar a un socio suspendido.
- [ ] Permite cancelar una reserva.
- [ ] La ficha muestra próximas clases.
- [ ] Los datos pertenecen únicamente al negocio autenticado.
