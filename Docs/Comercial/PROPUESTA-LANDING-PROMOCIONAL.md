# Propuesta — Página web promocional

## Inversión

- Diseño, adaptación y publicación: **$80.000**.
- Dominio `.com.ar`: se abona aparte al costo vigente de NIC Argentina.

El dominio se registra a nombre del cliente. Briva acompaña la configuración, pero la titularidad siempre pertenece al negocio.

## Incluye

- Landing basada en una plantilla del portfolio de Briva.
- Hasta cinco secciones.
- Adaptación de colores, identidad y textos breves.
- Hasta ocho imágenes proporcionadas por el cliente, preparadas y optimizadas para la web.
- Diseño adaptado a celulares, tablets y computadoras.
- WhatsApp, formulario básico y mapa o ubicación cuando corresponda.
- Configuración técnica y publicación.
- Dos rondas de correcciones.

Adicional disponible: carrusel de hasta diez imágenes por **$15.000** al contratarlo junto con la landing.

## Forma de trabajo

1. Definimos el objetivo y el alcance.
2. El cliente entrega el material necesario.
3. Briva presenta una primera versión privada en hasta siete días hábiles.
4. Se realizan hasta dos rondas de correcciones.
5. El cliente aprueba la versión final.
6. Después de acreditarse el pago, Briva conecta el dominio y publica la página definitiva.

Cada ronda se envía como una lista unificada dentro de los siete días corridos siguientes. Briva dispone de hasta tres días hábiles para aplicarla.

Durante la etapa promocional no se solicita anticipo. No existe una cuota mensual obligatoria. La renovación anual del dominio y los cambios posteriores se abonan por separado.

## No incluye

- Logo o identidad profesional desde cero.
- Sesión fotográfica o redacción extensa.
- Cambios ilimitados.
- Reservas con disponibilidad, pagos, catálogos administrables, usuarios, stock o funciones no indicadas.

Después de treinta días sin respuesta, el proyecto puede quedar pausado y su reanudación puede requerir una nueva cotización.
