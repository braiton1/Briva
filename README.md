# Briva

Soluciones digitales para pequeños negocios.

## Objetivo

Crear la experiencia que ven los clientes y las herramientas internas que necesita cada negocio para trabajar mejor, sin tocar código.

## Proyectos

- **Sitio de Briva:** presentación de servicios, proceso y cartera de proyectos.
- **NÚCLEO Training:** sitio conceptual para un gimnasio, con clases, planes, horarios, ubicación y panel demostrativo.
- **Briva Gestión:** plataforma local multiempresa con autenticación, roles, base de datos y herramientas adaptadas a cada negocio.

## Enfoque

- Sitios y landing pages.
- Paneles de gestión.
- Ventas online.
- Automatizaciones e integraciones.
- Soporte y evolución del producto.

## Estado

🚧 Proyecto en construcción. La plataforma de gestión funciona localmente con datos ficticios y todavía no está preparada para producción.
