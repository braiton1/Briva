# NÚCLEO Training — Diseño v1

## Objetivo

Crear una landing moderna para un gimnasio pequeño que busca conseguir consultas y clases de prueba.

## Acción principal

Solicitar una clase de prueba.

## Acción secundaria

Ver horarios.

## Dirección visual

- Fondo blanco cálido.
- Secciones oscuras para generar contraste.
- Verde lima como color de acción.
- Tipografía grande y deportiva.
- Fotografías naturales.
- Diseño cercano y apto para principiantes.

## Secciones

1. Header.
2. Hero.
3. Beneficios principales.
4. Tipos de entrenamiento.
5. Planes.
6. Horarios.
7. Instalaciones.
8. Preguntas frecuentes.
9. Ubicación.
10. WhatsApp.
11. Footer.
