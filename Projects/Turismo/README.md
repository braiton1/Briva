# Casa Jarilla — Demo conceptual

Landing de reservas para dos cabañas pequeñas en Potrerillos, Mendoza.

## Objetivo

Mostrar el alojamiento, sus comodidades y el entorno; permitir que una persona seleccione fechas, huéspedes y cabaña para consultar disponibilidad por WhatsApp.

Todos los nombres, precios, testimonios y datos comerciales son ficticios. Las tarifas toman referencias generales publicadas para Potrerillos y se utilizan únicamente con fines demostrativos.

## Propuesta

- Dos cabañas: Jarilla Chica y Jarilla Familiar.
- Ubicación conceptual: Las Vegas, Potrerillos.
- Reserva directa sin intermediarios.
- Conversión principal: consulta de disponibilidad por WhatsApp.
- Estética: paisaje andino, piedra, madera y vegetación nativa.

## Arquitectura

Contenido centralizado en `src/data/siteContent.ts`, secciones separadas en componentes y formulario de consulta que arma un mensaje con fechas, huéspedes y alojamiento elegido.
