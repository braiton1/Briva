# Andina Reformas — Demo conceptual

Landing de captación para una pequeña empresa de remodelaciones en San Rafael, Mendoza.

## Objetivo

Mostrar trabajos, explicar el proceso y recibir solicitudes calificadas de presupuesto por WhatsApp.

El negocio, los testimonios, proyectos y datos comerciales son ficticios. No se publican precios cerrados porque una remodelación depende de medidas, estado actual, materiales y alcance.

## Propuesta

- Cocinas, baños, ampliaciones y reformas integrales.
- Cobertura conceptual: San Rafael y alrededores.
- Comunicación clara y seguimiento de obra.
- Conversión principal: solicitud detallada de visita y presupuesto.

## Arquitectura

Contenido comercial centralizado, secciones modulares y formulario que clasifica el tipo de obra, ambiente, etapa y rango de inversión antes de preparar el mensaje de WhatsApp.
